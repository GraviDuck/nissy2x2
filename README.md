# nissy2x2
A remake of nissy for 3x3 fmc, but instead for 2x2 fmc. It gives the optimal solution of any 2x2 scramble (11 moves or less).Compiler: pyinstaller --onefile --add-data "*:." example.py You need to generate prun tables. Firstly run the example.py and then it will generate the tables. then exit, and compile.  The .elf/.exe will be in dist
