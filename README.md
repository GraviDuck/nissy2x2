# nissy2x2
                                     CREDITS TO SEBASTIANO TRONTO FOR HAVING THE ORIGINAL IDEA

A remake of nissy for 3x3 fmc, but instead for 2x2 fmc. It gives the optimal solution of any 2x2 scramble (11 moves or less).Compiler: pyinstaller --onefile --add-data "*:." example.py. The .elf/.exe will be in dist
(You need to download pyinstaller from pip)
